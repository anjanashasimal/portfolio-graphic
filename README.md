# Anjana Bandara — Portfolio (React + Vite)

## Run
npm install
npm run dev

## Edit your work
Open src/App.jsx. At the top you'll find:
- PROFILE  -> name, phone, email
- PROJECTS -> your main work cards (add `image` and `link`)
- MORE_WORK -> the list under the cards

Put images in src/ and import them, e.g.
  import cafeLogo from "./work/cafe-logo.jpg";
  { title: "Brand identity for a café", image: cafeLogo, link: "https://behance.net/..." }

## Deploy (free)
npm run build  -> upload the dist/ folder to Netlify or Vercel.
